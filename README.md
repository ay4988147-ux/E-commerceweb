# MERN E-Commerce Website

A full-stack e-commerce website built using the MERN stack.

## Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features

- User Registration & Login
- Product Listing
- Search & Category Filter
- Shopping Cart
- Address Management
- Order Placement
- REST APIs
- MongoDB Database
